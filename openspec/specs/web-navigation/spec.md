# Web Navigation Specification

## Purpose

Совместимость адресов приложения: прежние адреса разделов, сохранённые пользователями в закладках
и разосланные в ссылках, продолжают открывать соответствующий раздел после того, как канонический
адрес изменился.

## Requirements

### Requirement: Прежние адреса разделов продолжают работать

Система SHALL перенаправлять запрос по прежнему адресу раздела на его канонический адрес
временным перенаправлением. Прежний адрес MUST NOT возвращать ошибку и MUST NOT приводить к
пустой странице.

#### Scenario: Открытие сохранённой закладки

- GIVEN у пользователя сохранён прежний адрес раздела
- WHEN он открывает его
- THEN браузер перенаправляется на канонический адрес и раздел открывается

### Requirement: Перечень поддерживаемых прежних адресов

Система SHALL поддерживать перенаправление: прежнего адреса доски целей — на её канонический
адрес; прежних адресов управления командами и периодами — на соответствующие разделы
администрирования; прежних адресов создания и редактирования команды, редактирования периода и
карточки пользователя — на раздел администрирования, который дальше открывает нужный экран
самостоятельно.

#### Scenario: Прежний адрес доски целей

- GIVEN пользователь открывает прежний адрес доски целей
- WHEN запрос обрабатывается
- THEN он попадает на каноническую доску целей

#### Scenario: Прежние адреса управления

- GIVEN пользователь открывает прежний адрес управления командами или периодами
- WHEN запрос обрабатывается
- THEN он попадает в соответствующий раздел администрирования

#### Scenario: Прежний адрес формы администрирования

- GIVEN пользователь открывает прежний адрес создания команды или редактирования периода
- WHEN запрос обрабатывается
- THEN он попадает в раздел администрирования

### Requirement: Строка запроса сохраняется для доски целей

Система SHALL переносить строку запроса при перенаправлении с прежнего адреса доски целей, чтобы
разосланные ранее ссылки с выбранными командой, периодом и целью открывали то же самое.

#### Scenario: Прежняя ссылка с параметрами

- GIVEN разослана ссылка на прежний адрес доски целей с параметрами команды, периода и цели
- WHEN получатель открывает её
- THEN после перенаправления открывается ровно та же команда, период и цель

### Requirement: Доступность перенаправлений соответствует разделу назначения

Система SHALL обрабатывать перенаправление прежних адресов управления командами и периодами без
требования активного членства, а перенаправление прежнего адреса доски целей — для участника с
активным членством. Права на сам раздел назначения SHALL проверяться этим разделом, а не
перенаправлением.

#### Scenario: Пользователь без членства открывает прежний адрес

- GIVEN у пользователя нет активного членства
- WHEN он открывает прежний адрес управления командами
- THEN перенаправление срабатывает, а дальнейший доступ решается правилами раздела назначения
