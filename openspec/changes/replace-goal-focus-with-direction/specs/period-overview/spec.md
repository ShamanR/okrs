## MODIFIED Requirements

### Requirement: Балансы целей

Система ОБЯЗАНА показывать распределение целей охвата по типу работы, направлению и приоритету.
Каждая корзина ОБЯЗАНА содержать все фиксированные категории, включая нулевые, с указанием доли
от числа целей охвата. Баланс по направлениям ОБЯЗАН называться «Направления целей», содержать
категории Продукт, Техника и Процессы в этом порядке и показывать у каждой категории её иконку.

#### Scenario: Категория без целей

- GIVEN в охвате нет ни одной цели направления «Процессы»
- WHEN пользователь смотрит баланс по направлениям
- THEN категория «Процессы» присутствует в списке с нулевым значением

#### Scenario: Баланс между направлениями

- GIVEN в охвате две цели направления «Продукт», одна «Техника» и одна «Процессы»
- WHEN пользователь смотрит баланс «Направления целей»
- THEN он видит Продукт 50%, Техника 25%, Процессы 25%

#### Scenario: Детализация по клику

- GIVEN пользователь видит распределение целей по приоритетам
- WHEN он выбирает конкретный приоритет
- THEN он видит цели охвата с этим приоритетом

#### Scenario: Детализация по направлению

- GIVEN пользователь видит баланс «Направления целей»
- WHEN он выбирает направление «Техника»
- THEN он видит цели охвата с направлением «Техника»

## ADDED Requirements

### Requirement: Направление цели в списке детализации

Каждая цель в списке целей детализации обзора ОБЯЗАНА показывать иконку своего направления
слева от заголовка. Иконка ОБЯЗАНА показывать подсказку согласно требованию «Подсказка по
иконке направления» доски команды.

#### Scenario: Иконка в детализации

- GIVEN пользователь открыл детализацию баланса по приоритету P1
- WHEN в списке есть цель направления «Продукт»
- THEN слева от её заголовка стоит иконка 🚀, а наведение на иконку показывает название и
  описание направления
