## MODIFIED Requirements

### Requirement: Поля цели

Система ОБЯЗАНА хранить у цели заголовок, описание, приоритет, вес, тип работы, направление и
драйверов цели. Драйверы ОБЯЗАНЫ выбираться из пользователей системы.

#### Scenario: Редактирование полей

- GIVEN существующая цель
- WHEN пользователь меняет её заголовок, приоритет, тип работы, направление или драйверов
- THEN изменения сохраняются и отображаются на карточке цели

## ADDED Requirements

### Requirement: Направление цели

Направление показывает, на какую область работы нацелена цель. У цели ОБЯЗАНО быть ровно одно
направление из фиксированного набора:

| Направление | Иконка | Описание |
| --- | --- | --- |
| Продукт | 🚀 | Развитие функциональности, ценность для пользователей, бизнес-результаты |
| Техника | ⚙️ | Архитектура, надёжность, безопасность, техническое качество |
| Процессы | 📈 | Эффективность, организация работы, автоматизация процессов |

Порядок направлений во всех списках, фильтрах и балансах ОБЯЗАН быть одним: Продукт, Техника,
Процессы.

Направление ОБЯЗАТЕЛЬНО. Новая цель ОБЯЗАНА получать направление «Продукт», если пользователь не
выбрал другое. Создание или изменение цели без направления или со значением вне набора ОБЯЗАНО
отклоняться как ошибка валидации, в том числе со значениями прежнего фокуса.

#### Scenario: Новая цель по умолчанию

- GIVEN пользователь открывает окно создания цели
- WHEN он сохраняет цель, не меняя направление
- THEN у цели направление «Продукт»

#### Scenario: Недопустимое направление

- GIVEN пользователь создаёт или редактирует цель через API
- WHEN он передаёт направление вне набора, например прежнее значение фокуса «Stability»
- THEN операция отклоняется как ошибка валидации, цель не меняется

#### Scenario: Копирование цели

- GIVEN у цели направление «Техника»
- WHEN пользователь копирует или переносит её в другую команду или период
- THEN у копии направление «Техника»

### Requirement: Перевод фокуса в направление

При переходе на направления каждая существующая цель ОБЯЗАНА получить направление по её фокусу:

| Фокус | Направление |
| --- | --- |
| Profitability | Продукт |
| Stability | Техника |
| Speed Efficiency | Процессы |
| Tech Independence | Техника |

После перехода у каждой цели ОБЯЗАНО быть направление. Фокус в интерфейсе и в API
отображать НЕОБХОДИМО не допускать.

#### Scenario: Перевод существующих целей

- GIVEN до перехода у целей фокусы Profitability, Stability, Speed Efficiency и Tech Independence
- WHEN система переходит на направления
- THEN цели получают направления Продукт, Техника, Процессы и Техника соответственно

#### Scenario: Цель после перехода

- GIVEN цель переведена из фокуса в направление
- WHEN пользователь открывает окно редактирования цели
- THEN он видит выбор направления с переведённым значением и не видит поля «Фокус»
