## MODIFIED Requirements

### Requirement: Состав карточки цели

Система SHALL показывать на карточке цели заголовок, приоритет, вес, тип работы, фокус,
драйверов цели, описание цели, прогресс с отметкой ожидаемого темпа и индикатор здоровья, а
также раскрываемые блоки ключевых результатов и обсуждения. Описание цели SHALL отображаться
с сохранением разметки и в свёрнутом виде, если оно превышает ограничение по высоте.

#### Scenario: Просмотр карточки

- GIVEN у цели заполнены метаданные и есть ключевые результаты
- WHEN пользователь открывает доску
- THEN на карточке отображаются метаданные, описание, прогресс и раскрываемые блоки

#### Scenario: Цель без описания

- GIVEN у цели не заполнено описание
- WHEN пользователь открывает доску
- THEN на карточке не отображается ни блок описания, ни элемент разворачивания

## ADDED Requirements

### Requirement: Свёрнутое отображение длинного описания на доске

Система SHALL ограничивать высоту отображаемого описания цели и описания ключевого результата
в карточке цели на доске. Если описание не помещается в ограничение, система SHALL показывать
только помещающуюся часть, визуально обозначать наличие скрытого текста затенением нижней
границы видимой части и показывать элемент разворачивания. Ограничение для описания цели SHALL
быть больше ограничения для описания ключевого результата.

Скрытие непоместившейся части SHALL сохранять разметку описания: списки, заголовки и абзацы
видимой части SHALL отображаться так же, как при полном показе описания.

#### Scenario: Длинное описание цели свёрнуто

- GIVEN описание цели превышает ограничение по высоте для описания цели
- WHEN пользователь открывает доску
- THEN отображается только помещающаяся часть описания с затенённой нижней границей и элементом
  разворачивания

#### Scenario: Длинное описание ключевого результата свёрнуто

- GIVEN описание ключевого результата превышает ограничение по высоте для описания
  ключевого результата
- WHEN пользователь раскрывает блок ключевых результатов цели
- THEN описание этого ключевого результата отображается свёрнутым с затенением и элементом
  разворачивания

#### Scenario: Короткое описание не обрезается

- GIVEN описание целиком помещается в ограничение по высоте
- WHEN пользователь открывает доску
- THEN описание отображается полностью, без затенения и без элемента разворачивания

#### Scenario: Разметка видимой части сохраняется

- GIVEN описание содержит заголовки и маркированные списки и превышает ограничение
- WHEN описание отображается свёрнутым
- THEN видимая часть сохраняет исходную разметку, а не превращается в неформатированный текст

### Requirement: Разворачивание и сворачивание описания на доске

Система SHALL позволять пользователю развернуть свёрнутое описание до полного и свернуть его
обратно, не покидая доску и не открывая редактор. Разворачивание описания SHALL не изменять
данные цели или ключевого результата и SHALL не запускать других действий карточки —
перехода в редактирование, перетаскивания или раскрытия блоков.

Разворачивание SHALL действовать на одно конкретное описание: описания других целей и других
ключевых результатов SHALL оставаться в прежнем состоянии.

#### Scenario: Разворачивание описания

- GIVEN описание цели отображается свёрнутым
- WHEN пользователь активирует элемент разворачивания
- THEN описание отображается полностью, затенение исчезает, а элемент переключается в
  сворачивание

#### Scenario: Сворачивание обратно

- GIVEN описание цели развёрнуто пользователем
- WHEN пользователь активирует элемент сворачивания
- THEN описание возвращается к свёрнутому виду с затенением и элементом разворачивания

#### Scenario: Разворачивание не затрагивает соседние описания

- GIVEN на доске несколько целей с длинными описаниями
- WHEN пользователь разворачивает описание одной цели
- THEN описания остальных целей и их ключевых результатов остаются свёрнутыми

#### Scenario: Разворачивание не открывает редактор

- GIVEN пользователь имеет право редактировать цель
- WHEN пользователь активирует элемент разворачивания описания
- THEN окно редактирования цели не открывается и данные цели не изменяются

### Requirement: Состояние разворачивания описания не сохраняется

Система SHALL считать развёрнутое состояние описания временным. Состояние SHALL не
сохраняться ни на сервере, ни в браузере участника: после перезагрузки страницы, смены
команды или смены периода все длинные описания SHALL снова отображаться свёрнутыми.

#### Scenario: Перезагрузка страницы

- GIVEN пользователь развернул описание цели
- WHEN пользователь перезагружает страницу доски
- THEN описание этой цели снова отображается свёрнутым

#### Scenario: Смена команды или периода

- GIVEN пользователь развернул описание цели
- WHEN пользователь переключается на другую команду или другой период и возвращается обратно
- THEN описание этой цели снова отображается свёрнутым

### Requirement: Обрезание описаний ограничено доской команды

Система SHALL применять свёрнутое отображение описаний только к карточке цели и строке
ключевого результата на доске команды. В остальных местах, где показывается описание цели или
ключевого результата, описание SHALL отображаться полностью, как прежде.

#### Scenario: Окно обновления прогресса

- GIVEN у ключевого результата длинное описание
- WHEN пользователь открывает окно обновления прогресса этого ключевого результата
- THEN описание отображается полностью, без затенения и без элемента разворачивания

#### Scenario: Экспорт цели

- GIVEN у цели длинное описание
- WHEN цель выгружается через экспорт
- THEN выгрузка содержит полное описание цели
