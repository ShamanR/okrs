## MODIFIED Requirements

### Requirement: Ссылка в доставленном сообщении открывается извне продукта

Ссылка в сообщении, отправленном во внешний канал, ОБЯЗАНА быть абсолютной. Она ведёт на
цель, а для уведомления о заявке на доступ — в очередь заявок пространства. Относительная
ссылка в мессенджере не работает: она либо остаётся текстом, который нельзя нажать, либо
разрешается относительно адреса самого мессенджера и ведёт не туда.

Если у развёртывания не настроен собственный адрес, ссылка отправляться НЕ
ДОЛЖНА — сообщение при этом уходит без неё. Ссылка, которую нельзя открыть,
хуже её отсутствия.

Ссылка на цель, которой больше нет, отправляться НЕ ДОЛЖНА. Уведомление об
удалении цели создаётся, когда сама цель уже удалена, а её идентификатор запись
уведомления переживает — ссылка, построенная по нему, привела бы читателя к
тому, чего не существует. Само сообщение при этом уходит: об удалении надо
сообщить, вести по ссылке — некуда.

Внешний вид ссылки НЕОБХОДИМО относить к самому каналу: способ сделать её
нажимаемой определяется тем, как принимающая сторона отображает сообщения.

#### Scenario: Адрес продукта настроен

- GIVEN у развёртывания настроен собственный адрес
- WHEN получателю уходит сообщение об уведомлении, привязанном к цели
- THEN ссылка в сообщении абсолютная и открывает эту цель

#### Scenario: Адрес продукта не настроен

- GIVEN у развёртывания не настроен собственный адрес
- WHEN получателю уходит сообщение
- THEN сообщение доставляется без ссылки, а не со ссылкой, которую нельзя открыть

#### Scenario: Уведомление не привязано к цели

- GIVEN уведомление не указывает на цель и не является уведомлением о заявке на доступ
- WHEN формируется сообщение
- THEN ссылки в нём нет

#### Scenario: Цель удалена

- GIVEN уведомление сообщает об удалении цели
- WHEN формируется сообщение
- THEN оно доставляется без ссылки, потому что открывать уже нечего

#### Scenario: Уведомление о заявке на доступ

- GIVEN у развёртывания настроен собственный адрес
- WHEN администратору уходит сообщение о новой заявке на доступ
- THEN сообщение называет заявителя и пространство, а абсолютная ссылка открывает очередь заявок этого пространства
