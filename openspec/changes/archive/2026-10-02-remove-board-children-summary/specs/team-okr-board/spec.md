## ADDED Requirements

### Requirement: Доска показывает только собственные цели узла

Система ОБЯЗАНА начинать содержимое доски со списка целей выбранной команды за выбранный период и
НЕОБХОДИМО не показывать на доске цели и показатели её дочерних команд. Пустое состояние «цели не
добавлены» ОБЯЗАНО определяться отсутствием собственных целей узла в периоде и НЕОБХОДИМО не
зависеть от наличия у узла дочерних команд.

#### Scenario: Узел с дочерними командами и своими целями

- GIVEN у выбранного узла есть дочерние команды и есть свои цели в периоде
- WHEN пользователь открывает его доску
- THEN он видит только цели этого узла, без показателей дочерних команд

#### Scenario: Узел с дочерними командами без своих целей

- GIVEN у выбранного узла есть дочерние команды, но нет своих целей в периоде
- WHEN пользователь открывает его доску
- THEN доска показывает пустое состояние «цели не добавлены», как у узла без потомков

#### Scenario: Переход в дочернюю команду

- GIVEN у выбранного узла есть дочерние команды
- WHEN пользователь переходит в одну из них
- THEN он делает это из дерева навигации, где у каждой дочерней команды виден её прогресс

## REMOVED Requirements

### Requirement: Сводка по дочерним командам

**Reason**: Сводка дублирует дерево навигации, занимает первый экран доски и используется редко.
Блок удаляется с доски целиком вместе с эндпоинтом `GET /api/v1/teams/{teamID}/overview`.

**Migration**: Переход в дочернюю команду и её прогресс остаются в дереве навигации — см.
requirement «Показатели узла в дереве навигации».

### Requirement: Показатели сводки по дочерним командам

**Reason**: Удаляется вместе со сводкой. Средний прогресс по подчинённой иерархии больше нигде не
показывается; прогресс самого узла остаётся на доске, прогресс каждой дочерней команды — в дереве.

**Migration**: Нет. Прогресс по каждой дочерней команде виден в дереве навигации.

### Requirement: Строка дочерней команды в сводке

**Reason**: Удаляется вместе со сводкой: строк дочерних команд на доске не остаётся.

**Migration**: Нет. В дереве навигации по дочерней команде видны название, тип и прогресс; статус,
счётчики целей и лид на доске больше не показываются.

### Requirement: Момент последнего обновления дочерней команды

**Reason**: Удаляется вместе со сводкой; это был единственный потребитель момента последнего
обновления в разрезе команды.

**Migration**: Нет. Давность обновления остаётся на уровне цели — см. requirement
«Предупреждение «нет обновлений» на карточке цели».

### Requirement: Сводка требует периода и не изменяет данные

**Reason**: Описывает контракт эндпоинта сводки, который удаляется.

**Migration**: Нет. Эндпоинт `GET /api/v1/teams/{teamID}/overview` удаляется целиком.
