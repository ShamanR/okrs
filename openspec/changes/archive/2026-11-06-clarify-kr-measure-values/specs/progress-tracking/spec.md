## ADDED Requirements

### Requirement: Прогресс числового KR до первого обновления прогресса

Система SHALL считать прогресс числового ключевого результата, прогресс которого ни разу не
обновляли, по общим правилам расчёта от текущего значения, равного стартовому.

Правка стартового или целевого значения такого результата MUST NOT приводить к прогрессу,
вычисленному от прежнего стартового значения.

#### Scenario: Прогресс только что созданного результата

- GIVEN создан числовой ключевой результат со стартовым значением 0 и целевым 200, прогресс ни
  разу не обновляли
- WHEN вычисляется прогресс
- THEN прогресс равен 0

#### Scenario: Прогресс после правки стартового значения до первого обновления

- GIVEN у числового ключевого результата стартовое значение 0, целевое 200, прогресс ни разу не
  обновляли
- WHEN стартовое значение меняется на 100
- THEN прогресс остаётся равным 0

## MODIFIED Requirements

### Requirement: Обновление прогресса ключевого результата

Система SHALL позволять обновлять прогресс ключевого результата способом, соответствующим его
типу: числовое текущее значение, отметка выполнения, отметки завершённых этапов. Обновление
прогресса SHALL проверять доступ к команде-владельцу цели на сервере.

Обновление прогресса SHALL быть единственным способом изменить текущее значение числового
ключевого результата. Редактирование определения результата — названия, описания, веса,
стартового и целевого значений, единицы измерения, промежуточных значений — MUST NOT менять
текущее значение.

#### Scenario: Обновление прогресса в доступной команде

- GIVEN пользователю доступна команда-владелец цели
- WHEN он обновляет прогресс её ключевого результата
- THEN значение сохраняется и прогресс цели пересчитывается

#### Scenario: Обновление прогресса вне области видимости

- GIVEN команда-владелец цели недоступна пользователю
- WHEN он пытается обновить прогресс ключевого результата
- THEN возвращается «не найдено», значение не меняется

#### Scenario: Правка определения не меняет текущее значение

- GIVEN у числового ключевого результата прогресс обновляли до 150
- WHEN пользователь сохраняет правку его стартового значения, целевого значения и единицы
  измерения
- THEN текущее значение остаётся равным 150
