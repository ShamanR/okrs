## MODIFIED Requirements

### Requirement: Режимы редактирования выводятся из статуса

Система ОБЯЗАНА выводить режим редактирования доски из статуса команды в периоде: при «нет
целей», «черновик» и «к валидации» доступно полное редактирование; при «в работе» интерфейс
предлагает обновление прогресса и комментарии; при «закрыт» — только комментарии.

Действие, недоступное в текущем режиме, ОБЯЗАНО отображаться заблокированным на своём обычном
месте, а не исчезать из интерфейса. Заблокированное действие ОБЯЗАНО нести признак блокировки и
ОБЯЗАНО объяснять причину — текущий статус команды в периоде — при наведении и при получении
фокуса с клавиатуры. Заблокированное действие НЕОБХОДИМО не выполнять при активации.

#### Scenario: Режим полного редактирования

- GIVEN статус команды — «черновик»
- WHEN пользователь открывает доску
- THEN ему доступны создание, редактирование и удаление целей и ключевых результатов

#### Scenario: Режим «только комментарии»

- GIVEN статус команды — «закрыт»
- WHEN пользователь открывает доску
- THEN интерфейс предлагает только работу с комментариями

#### Scenario: Недоступное действие остаётся видимым

- GIVEN статус команды — «в работе»
- WHEN пользователь открывает доску
- THEN действия добавления и удаления цели и ключевого результата видны на своих местах в
  заблокированном виде, а не отсутствуют

#### Scenario: Причина блокировки названа

- GIVEN статус команды — «в работе», на доске есть заблокированное действие
- WHEN пользователь наводит указатель на это действие или переводит на него фокус с клавиатуры
- THEN отображается объяснение, называющее текущий статус команды причиной блокировки

#### Scenario: Заблокированное действие не срабатывает

- GIVEN статус команды — «закрыт»
- WHEN пользователь активирует заблокированное действие редактирования ключевого результата
- THEN окно редактирования не открывается и данные не изменяются

## ADDED Requirements

### Requirement: Баннер режима редактирования на доске

Система ОБЯЗАНА показывать на доске команды, непосредственно под переключателем статусов, баннер
текущего режима редактирования. Баннер ОБЯЗАН называть текущий статус команды в периоде, что в
этом режиме доступно и что заблокировано.

Баннер ОБЯЗАН отображаться, когда режим отличается от полного редактирования. В режиме полного
редактирования баннер НЕОБХОДИМО не показывать.

Баннер ОБЯЗАН обновляться при смене статуса команды и при переключении команды или периода — без
перезагрузки страницы.

#### Scenario: Команда в работе

- GIVEN статус команды — «в работе»
- WHEN пользователь открывает доску
- THEN под переключателем статусов виден баннер, называющий статус «в работе», указывающий на
  доступность обновления прогресса и комментариев и на блокировку изменения состава целей

#### Scenario: Период закрыт

- GIVEN статус команды — «закрыт»
- WHEN пользователь открывает доску
- THEN баннер называет статус «закрыт» и указывает, что доступны только комментарии

#### Scenario: Полное редактирование

- GIVEN статус команды — «черновик»
- WHEN пользователь открывает доску
- THEN баннер режима не отображается

#### Scenario: Смена статуса на доске

- GIVEN открыта доска команды в статусе «к валидации», баннер не отображается
- WHEN пользователь переводит команду в «в работе»
- THEN баннер появляется и описывает новый режим без перезагрузки страницы
