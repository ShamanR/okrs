## MODIFIED Requirements

### Requirement: Порядок целей на доске

Система ОБЯЗАНА предлагать два порядка целей на доске: пользовательский и по приоритету.
Пользовательский порядок — порядок, заданный перетаскиванием целей, — ОБЯЗАН быть значением
по умолчанию.

Порядок по приоритету ОБЯЗАН выстраивать цели от высшего приоритета к низшему. Цели одного
приоритета ОБЯЗАНЫ сохранять между собой пользовательский порядок.

Порядок ОБЯЗАН менять только показ: порядок целей, сохранённый у команды в периоде, выбором
порядка на доске не меняется.

Перетаскивание целей меняет пользовательский порядок, поэтому при порядке по приоритету
перетаскивание целей ОБЯЗАНО быть недоступно, а средство перетаскивания цели — не
отображаться. Перетаскивание ключевых результатов внутри цели ОБЯЗАНО оставаться доступным
на тех же условиях, что и раньше.

Там, где перетаскивание цели или ключевого результата доступно, жест ОБЯЗАН начинаться
только от средства перетаскивания этой цели или этого ключевого результата и продолжаться,
когда указатель выходит за его границы: прерывать начатый жест по выходу указателя из
средства перетаскивания НЕОБХОДИМО не допускать. Нажатие в любом другом месте карточки
цели или строки ключевого результата НЕОБХОДИМО не превращать в перетаскивание: текст
в этих местах, в том числе название ключевого результата, ОБЯЗАН выделяться указателем.

#### Scenario: Порядок по приоритету

- GIVEN у команды цели в пользовательском порядке P2, P0, P1
- WHEN пользователь выбирает порядок по приоритету
- THEN цели показаны в порядке P0, P1, P2

#### Scenario: Цели одного приоритета сохраняют пользовательский порядок

- GIVEN у команды две цели приоритета P1, идущие в пользовательском порядке одна за другой
- WHEN пользователь выбирает порядок по приоритету
- THEN эти две цели идут в том же относительном порядке

#### Scenario: Сохранённый порядок не меняется

- GIVEN пользователь выбрал порядок по приоритету
- WHEN он возвращает пользовательский порядок
- THEN цели показаны в том же порядке, что и до выбора порядка по приоритету

#### Scenario: Перетаскивание недоступно при порядке по приоритету

- GIVEN пользователю доступно изменение порядка целей
- WHEN он выбирает порядок по приоритету
- THEN средство перетаскивания цели не отображается, а перетащить цель нельзя

#### Scenario: Жест выходит за пределы средства перетаскивания

- GIVEN пользователю доступно изменение порядка целей и выбран пользовательский порядок
- WHEN он нажимает средство перетаскивания цели и ведёт указатель за его пределы
- THEN перетаскивание цели начинается, а не отменяется, и бросок на другую цель меняет
  порядок

#### Scenario: Перетаскивание ключевых результатов не затронуто

- GIVEN пользователю доступно изменение порядка и выбран порядок по приоритету
- WHEN он перетаскивает ключевой результат внутри цели за его средство перетаскивания
- THEN порядок ключевых результатов цели меняется

#### Scenario: Ключевой результат перетаскивается за своё средство перетаскивания

- GIVEN цель в черновике, и пользователю доступно изменение порядка её ключевых результатов
- WHEN он нажимает средство перетаскивания ключевого результата, ведёт указатель за его
  пределы и бросает ключевой результат на другой ключевой результат той же цели
- THEN перетаскивание начинается, а не отменяется, и порядок ключевых результатов цели
  меняется

#### Scenario: Название ключевого результата выделяется

- GIVEN цель в черновике, и пользователю доступно изменение порядка её ключевых результатов
- WHEN он нажимает на название ключевого результата и ведёт указатель по тексту
- THEN текст названия выделяется, перетаскивание ключевого результата не начинается,
  а порядок ключевых результатов не меняется

#### Scenario: Нажатие вне средства перетаскивания не перетаскивает ключевой результат

- GIVEN пользователю доступно изменение порядка ключевых результатов цели
- WHEN он нажимает в строке ключевого результата вне средства перетаскивания — на
  описании, мере или прогрессе — и ведёт указатель за пределы строки
- THEN перетаскивание ключевого результата не начинается
