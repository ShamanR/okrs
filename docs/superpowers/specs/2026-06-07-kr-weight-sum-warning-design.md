# Подсветка несбалансированной суммы весов KR

## Проблема

Сумма весов keyResults внутри цели должна быть равна 100%. Сейчас отклонение
никак не подсвечивается в UI — пользователь не видит, что веса распределены
неполностью или с превышением.

## Решение

Клиентская индикация в `GoalCard` ([internal/web/static/tracker.js](../../../internal/web/static/tracker.js)).
Backend не меняется — все данные (`goal.krs[].weight`) уже приходят на клиент.

### Расчёт

```js
const krWeightSum   = (goal.krs || []).reduce((s, k) => s + (k.weight || 0), 0);
const krWeightOff   = krWeightSum !== 100;   // показываем всегда, в т.ч. при пустом списке KR
const krWeightDelta = 100 - krWeightSum;     // >0 — не распределено, <0 — превышено
```

### 1. Badge на кнопке показа KR

Рядом с текстом «Скрыть KR» / «KR (N)», в обоих состояниях (свёрнуто/раскрыто),
если `krWeightOff`. Красный pill: `⚠ {krWeightSum} %`.
Класс `.kr-weight-badge` (текст `#dc2626`, фон `#fef2f2`, бордер `#fecaca`).

### 2. Warn-блок в списке KR

В блоке `.kr-section` (виден только при раскрытии), над списком KR, если `krWeightOff`:

```
⚠  Сумма весов KR = {krWeightSum}%, ожидается 100% · {suffix}
```

- `krWeightDelta > 0` → `не распределено {krWeightDelta}%`
- `krWeightDelta < 0` → `превышено на {-krWeightDelta}%`

Класс `.kr-weight-warn` — красная плашка (фон `#fef2f2`, бордер `#fecaca`, текст `#dc2626`).

## Видимость

Всегда: в read-only и в edit. При пустом списке KR сумма = 0% → индикация показывается.

## Тесты

JS-фронтенд в репозитории без unit-тестов; проверка визуальная. Логика —
чистый расчёт суммы, без побочных эффектов.
