# FAQ — частые вопросы

Короткие ответы на типичные вопросы. Подробности — по ссылкам в соответствующих разделах.

## Доступ и навигация

**Я не вижу ни одной команды.**
Нет выданного доступа (гранта). Обратитесь к администратору. См. [Стартовая страница](index.md).

**Как открыть прошлый квартал?**
Выберите нужный период в сайдбаре — закрытые периоды остаются доступными для просмотра.

**Как поделиться своим экраном OKR с коллегой?**
Скопируйте URL — в нём закодированы команда и период. См. [Возможности интерфейса](interface.md#навигация-и-прямые-ссылки).

## Цели

**Сколько целей и KR заводить?**
Практика: 3–5 целей на команду, 2–5 KR на цель. См. [Как ставить цели](goals.md).

**Почему счётчик веса целей красный?**
Сумма весов целей превысила 100%. Веса всех целей в сумме должны давать 100%.

**В чём разница между Delivery и Discovery?**
Delivery — известный результат, который надо доставить. Discovery — исследование гипотезы.

**Что такое «Общая цель»?**
Одна цель, которую одновременно ведут несколько команд (любое число), — чтобы посадить их в одну лодку. Структура общая, веса у команд могут различаться. См. [Общие (шаренные) цели](shared-goals.md).

## Key Results

**Как выбрать тип KR?**

- Измеряется числом → **Числовой**.
- Делится на этапы → **Проектный**.
- Сделано / не сделано → **Бинарный**.

Шпаргалка — в разделе [Как заводить Key Results](key-results.md#как-выбрать-тип-быстрая-шпаргалка).

**Нет нужной единицы измерения.**
Список единиц закрытый, свободного текста нет. Выберите ближайшую подходящую.

**Зачем нужны промежуточные значения (чекпойнты)?**
Чтобы задать нелинейную шкалу прогресса для числового KR. См. [Промежуточные значения](key-results.md#промежуточные-значения-чекпойнты).

**Сумма весов этапов проектного KR красная.**
Веса этапов должны давать в сумме 100.

## Статусы и процесс

**Какие бывают статусы?**
Нет целей → Черновик → К валидации → В работе → Закрыты. См. [Жизненный цикл](lifecycle.md).

**Почему пропали кнопки добавления целей/KR?**
Команда в статусе «В работе» или «Закрыты» — структура зафиксирована. Доступны прогресс и/или комментарии.

**Можно ли вернуться на шаг назад?**
Технически да, но это организационная договорённость с лидом.

## Прогресс и заметки

**Где обновлять прогресс?**
Кнопка «Обновить прогресс» у KR в статусе «В работе». См. [Работа в середине квартала](mid-quarter.md).

**Чем заметка KR отличается от комментария к цели?**
Заметка — одна актуальная запись по KR (перезаписывается). Комментарий — тред обсуждения цели с авторами и датами.

**Что значит индикатор stale?**
Прогресс KR давно не обновлялся. Обновите значение.

## Интерфейс

**Как скрыть лишние команды из сайдбара?**
Настройка «Мой сайдбар» в `/settings`. См. [Возможности интерфейса](interface.md#персональные-настройки--settings).

**Где включить описание команды?**
В `/settings` → «Описание команд» (доступно лидам). Поддерживает Markdown.

**Где Markdown работает?**
В описаниях целей, KR, команд и в заметках. См. [Markdown](interface.md#markdown).
