# Product Overview

## Назначение

Система предназначена для ведения OKR нескольких команд внутри общей оргструктуры.
Базовая сущность просмотра — команда в рамках периода.

Система должна позволять:

- видеть иерархию команд (в рамках выданного пользователю доступа);
- просматривать OKR команды за выбранный период;
- создавать цели и KR;
- обновлять прогресс KR;
- комментировать цели и KR с фиксацией автора;
- расшаривать одну цель на несколько команд;
- управлять статусом периода для команды;
- авторизовываться через внешний OAuth2/OIDC провайдер;
- управлять доступом пользователей к иерархии команд.

## Что уже считается частью продукта

В текущем проекте реализованы:

- team hierarchy;
- periods;
- goals;
- key results типов PROJECT, NUMERICAL, BOOLEAN;
- comments с фиксацией author_user_id;
- team period statuses no_goals, forming, in_progress, validated, closed;
- shared goals через goal_shares;
- авторизация через OAuth2/OIDC (Google, GitHub, Keycloak) или режим без авторизации;
- расширяемый реестр провайдеров — новый провайдер подключается без изменений core-кода;
- управление доступом к иерархии на уровне пользователя (hierarchy grants);
- admin UI для управления командами, периодами и доступами пользователей;
- структурированное логирование каждого запроса с auth-полями.

## Ценность продукта

Продукт решает четыре задачи:

1. Делает OKR прозрачными по оргструктуре.
2. Позволяет фиксировать прогресс в едином формате.
3. Даёт единый контур для owner team и shared team при работе с общей целью.
4. Управляет тем, кто и какую часть иерархии видит, без дублирования данных.
