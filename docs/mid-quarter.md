# Работа в середине квартала

Когда цели согласованы, команда переходит в статус **«В работе»**. Здесь структура целей и Key Results уже зафиксирована — кнопки создания и удаления скрыты. Основная активность теперь — **обновление прогресса** и **заметки**.

> 📷 **Скриншот:** `images/in-progress-card.png` — карточка цели в статусе «В работе»: прогресс-бар с отметкой прогноза, индикатор здоровья, список KR с кнопкой «Обновить прогресс».

---

## Что доступно в статусе «В работе»

| Можно | Нельзя (структура зафиксирована) |
| --- | --- |
| Обновлять прогресс Key Results | Создавать / удалять цели |
| Писать заметки к KR | Создавать / удалять KR |
| Комментировать цели | Менять тип, вес, состав KR |

Если нужно изменить структуру — это организационное решение: вернуть команду в «Черновик»/«К валидации» (по договорённости с лидом). См. [Жизненный цикл](lifecycle.md).

---

## How-to: обновить прогресс Key Result

1. Откройте команду и текущий период.
2. Раскройте блок Key Results у нужной цели.
3. Нажмите кнопку **«Обновить прогресс»** у KR.
4. В открывшемся окне обновите значение — поле зависит от типа KR (см. ниже).
5. При необходимости заполните **заметку**.
6. Нажмите **«Сохранить»**.

> 📷 **Скриншот:** `images/kr-progress-modal.png` — окно «Обновить прогресс»: блок «Описание» (справка), поле значения по типу KR, ориентир по шагам и блок «Заметка».

### Обновление по типам KR

- **Числовой (NUMERICAL):** введите **текущее значение**. Под полем показывается диапазон `старт → цель`, рассчитанный прогресс и (если заданы чекпойнты) **«Ориентир по шагам»** — сколько осталось до следующего промежуточного значения или цели. Если задан критерий обнуления, он отображается напоминанием.
- **Бинарный (BOOLEAN):** отметьте чекбокс **«Выполнено»** (100%) или снимите его (0%).
- **Проектный (PROJECT):** отметьте галочками завершённые **шаги** — прогресс пересчитается как сумма весов выполненных шагов.

В окне обновления прогресса также показывается блок **«Описание»** KR (только для справки/контекста). Если описания нет, можно нажать **«Добавить описание»** — введённый текст сохранится вместе с прогрессом.

## Заметки к Key Result

Заметка — это **актуальный контекст по KR**: блокеры, пояснения, что сделано. У каждого KR одна заметка (она перезаписывается, а не накапливается тредом), фиксируются автор и дата обновления.

### How-to: написать заметку

1. Откройте у KR окно **«Обновить прогресс»**.
2. В блоке **«Заметка (опционально)»** напишите текст.
3. Заметка поддерживает [Markdown](interface.md#markdown) (например, списки блокеров).
4. Нажмите **«Сохранить»** — под заметкой появятся автор и дата.

> 📷 **Скриншот:** `images/kr-note.png` — блок «Заметка» в окне обновления прогресса с автором и датой последнего обновления.

> 💡 **Где что писать:**
> - **Заметка KR** — текущее состояние конкретного результата (блокеры, контекст). Одна на KR, перезаписывается.
> - **Комментарий к цели** — обсуждение цели в целом (тред с авторами и датами). См. [Валидация и комментарии](validation.md).

## Чек-ины и здоровье прогресса

«Чек-ин» в середине квартала — это регулярное обновление прогресса всех Key Results и заметок. Чтобы понимать, идёт ли команда по плану, интерфейс показывает индикаторы здоровья.

### Прогноз (forecast) и индикатор здоровья

- На прогресс-баре есть **отметка прогноза** — где команда «должна» быть исходя из доли прошедшего времени квартала.
- Сравнение факта с прогнозом даёт статус здоровья:

| Индикатор | Что означает |
| --- | --- |
| **ahead** (опережение) | Факт заметно выше прогноза |
| **on track** (в графике) | Отклонение в пределах ±10 |
| **below** (отстаём) | Факт заметно ниже прогноза |
| **stale** (давно не обновляли) | Прогресс давно не обновлялся |

> 📷 **Скриншот:** `images/progress-forecast.png` — прогресс-бар с отметкой прогноза и цветовым индикатором здоровья.

> 💡 Регулярно обновляйте прогресс, чтобы KR не уходили в статус **stale** — это сигнал, что данные устарели.

### Health Check-in

В системе есть сводка **Health Check-in**, которая по вашим командам собирает проблемные места за период: устаревшие (stale), без целей, ожидающие валидации, ошибки формирования, отстающие. Используйте её, чтобы быстро увидеть, где нужно вмешаться.

> 📷 **Скриншот:** `images/health-checkin.png` — сводка Health Check-in с категориями проблем и счётчиками.

## FAQ

**Я не вижу кнопок добавить/удалить KR.**
Это нормально для статуса «В работе» — структура зафиксирована, доступно только обновление прогресса и заметки.

**Заметка пропала после того, как я написал новую?**
У KR одна заметка — новая перезаписывает старую. Для истории обсуждений используйте комментарии к цели.

**Что такое «Ориентир по шагам» при обновлении числового KR?**
Это подсказка по чекпойнтам: какой следующий рубеж и сколько до него осталось. Появляется, если у KR заданы промежуточные значения.

**Как часто делать чек-ины?**
Минимум раз в неделю или по договорённости команды — чтобы прогресс был актуальным и KR не уходили в stale.
