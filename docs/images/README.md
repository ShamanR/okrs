# Скриншоты для инструкции

Здесь должны лежать скриншоты, на которые ссылается документация. Имена файлов и содержимое:

| Файл | Что должно быть на скриншоте |
| --- | --- |
| `+tracker-overview.png` | Общий вид `/teamOkrs`: сайдбар, topbar с прогрессом, степпер, карточки целей |
| `interface-overview.png` | Та же страница с подписанными зонами интерфейса |
| `+status-stepper.png` | Степпер статусов: Черновик → К валидации → В работе → Закрыты |
| `+status-ready.png` | Степпер с подсвеченным шагом «К валидации» |
| `+status-closed.png` | Степпер с подсвеченным шагом «Закрыты» |
| `+goal-add-button.png` | Кнопка «+ Добавить цель» в topbar |
| `+goal-modal.png` | Модальное окно «Новая цель» со всеми полями |
| `+.png` | Включённый переключатель «Общая цель» и выбор команд |
| `+goal-card-shared.png` | Карточка общей цели с баннером «Общая с: …» и пометкой «· Вы» |
| `+goal-comments.png` | Раскрытый блок комментариев под карточкой цели |
| `+kr-modal.png` | Модальное окно «Добавить KR» с полями и выбором типа |
| `+kr-boolean.png` | Параметры бинарного KR: чекбокс «Выполнено» (0% / 100%) |
| `+kr-project.png` | Параметры проектного KR: шаги с весами и индикатор «Сумма: 100» |
| `+kr-numerical.png` | Параметры числового KR: старт, единица, цель, текущее, чекпойнты, критерий обнуления |
| `+kr-progress-modal.png` | Окно «Обновить прогресс»: описание, значение по типу, ориентир по шагам, заметка |
| `+kr-note.png` | Блок «Заметка» с автором и датой |
| `+progress-forecast.png` | Прогресс-бар с отметкой прогноза и индикатором здоровья |
| `+health-checkin.png` | Сводка Health Check-in с категориями проблем |
| `+in-progress-card.png` | Карточка цели в статусе «В работе» с кнопкой «Обновить прогресс» |
| `+cluster-overview.png` | Блок cluster overview для родительской команды |
| `+markdown-editor.png` | Редактор Markdown с предпросмотром |
| `settings-page.png` | Страница `/settings`: «Описание команд» и «Мой сайдбар» |
| `closing-summary.png` | Карточки целей закрытого квартала с итоговым прогрессом |
