# Возможности интерфейса

Этот раздел описывает элементы интерфейса OKR Tracker, которые помогают в работе: навигацию, ссылки, индикаторы, Markdown и персональные настройки.

> 📷 **Скриншот:** `images/interface-overview.png` — страница `/teamOkrs` целиком с подписанными зонами: сайдбар, topbar, степпер, карточки целей.

---

## Структура страницы команды

### Сайдбар (слева)

- **Дерево команд** — иерархия в пределах вашего доступа. Узлы с детьми разворачиваются по клику; состояние раскрытия запоминается между сессиями.
- **Выбор периода** — переключение между кварталами.
- **Виджет аккаунта** (внизу) — аватар, имя, выход, ссылка на **Настройки**, а у администраторов — ссылка на админ-панель.

### Основная область (справа)

- **Topbar** — название команды и общий прогресс за период.
- **Степпер статусов** — текущий этап квартала (см. [Жизненный цикл](lifecycle.md)).
- **Список карточек целей** — с прогрессом, метаданными, Key Results и комментариями.
- **Cluster overview** — для команд с дочерними командами над списком целей показывается агрегированный обзор по всей подчинённой иерархии (средний прогресс, число команд с целями, распределение по приоритетам и типам работы).

> 📷 **Скриншот:** `images/cluster-overview.png` — блок cluster overview для родительской команды со сводкой по дочерним командам.

## Карточка цели

На карточке цели отображаются:

- заголовок, приоритет (P0–P3), вес, тип работы (Delivery/Discovery), фокус, владелец;
- **прогресс-бар** с отметкой прогноза (forecast) и индикатором здоровья (ahead / on track / below / stale);
- для общих целей — баннер **«Общая с:»** со списком команд-партнёров (ваша команда помечена «· Вы»);
- раскрывающийся блок **Key Results**;
- раскрывающийся блок **Комментарии**.

В режиме полного редактирования на карточке доступны иконка карандаша (редактировать) и красный крестик (удалить).

## Навигация и прямые ссылки

- Текущая команда и период всегда отражаются в адресе: `/teamOkrs?team={id}&period={id}`.
- **Можно скопировать ссылку и отправить коллеге** — он откроет ровно тот же узел и период.
- Кнопки браузера **«Назад» / «Вперёд»** перемещают между ранее открытыми командами и периодами.
- Последнее открытое место запоминается — при повторном входе вы вернётесь туда же.

## Markdown {#markdown}

Текстовые поля **Описание** (у цели, Key Result и команды), а также **заметки** и часть текстов поддерживают подмножество Markdown:

- **жирный**, *курсив*, заголовки;
- списки и нумерованные списки;
- цитаты;
- `инлайн-код`;
- ссылки (открываются в новой вкладке).

В редакторе есть предпросмотр. Используйте Markdown, чтобы структурировать описания целей, расписать этапы или перечислить блокеры в заметках.

> 📷 **Скриншот:** `images/markdown-editor.png` — редактор Markdown с вкладкой предпросмотра.

## Персональные настройки — `/settings`

Открываются из меню пользователя (аватар в сайдбаре → «Настройки»). Доступны два раздела:

### Мой сайдбар

Выбор команд, которые показываются в дереве сайдбара трекера. Удобно скрыть лишнее и оставить только свои команды.

- У каждого узла три состояния: ничего не выбрано / выбрана вся ветка / выбрана часть.
- Есть поиск, «Выбрать все», «Снять все».
- Текущая открытая команда видна всегда.

### Описание команд (только для лидов)

Если вы лид хотя бы одной команды, вы можете добавить или изменить **описание команды** (с Markdown-редактором и предпросмотром). Описание видно в трекере.

> 📷 **Скриншот:** `images/settings-page.png` — страница `/settings` с разделами «Описание команд» и «Мой сайдбар».

## Индикаторы здоровья и прогноз

- На прогресс-баре отметка прогноза показывает ожидаемый уровень на текущую дату квартала.
- Цвет/индикатор здоровья: **ahead** (опережение), **on track** (в графике, отклонение ±10), **below** (отстаём), **stale** (давно не обновляли).
- Подробнее — в разделе [Работа в середине квартала](mid-quarter.md#чек-ины-и-здоровье-прогресса).

## FAQ

**Почему я не вижу некоторые команды в сайдбаре?**
Либо они скрыты вашей настройкой «Мой сайдбар», либо у вас нет к ним доступа. Проверьте `/settings` и при необходимости обратитесь к администратору.

**Я лид, но не вижу раздел «Описание команд» в настройках.**
Раздел виден только лидам команд в пределах вашего доступа. Если вы не назначены лидом ни одной команды, раздел скрыт.

**Можно ли поделиться конкретной целью?**
Скопируйте URL страницы команды с нужным периодом — коллега откроет тот же контекст. Прямой ссылки на отдельную цель нет.
